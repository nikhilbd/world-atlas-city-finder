# 🌍 World Atlas City Finder

**▶️ [Play Live on GitHub Pages](https://nikhilbd.github.io/world-atlas-city-finder/)**

An interactive, zero-dependency point-and-click geography and discovery game built with HTML5 Canvas.

## ✨ Features

- **199 Global Cities & 176 Country Polygons**: Play across three atlas densities (**85 Standard**, **148 Dense**, or **199 Mega Atlas**) with a 5-ring non-overlapping cartographic label engine.
- **Post-Find "City Discovery Postcard"**: Every found city opens a rich postcard with **2 visual cards** (custom SVG illustrations + live Wikipedia Commons photography), **vital geographic stats** (metro population, elevation, UTC offset, climate zone), and **2–3 lines of historical & geographic significance**.
- **🕵️ Geo-Detective Riddle Mode (`1.5×` Points)**: Switch from city names to geographic & historical riddles.
- **Curated Themed Expeditions**:
  - 🏺 **Silk Road & Ancient Capitals (58)**
  - 🏔️ **Extreme Earth: High, Cold & Remote (45)**
  - ⚓ **Global Chokepoints & Great Ports (87)**
  - Regional focus decks (**Americas**, **Europe**, **Africa**, **Asia & Oceania**)
- **Smarter Wrong-Click Feedback**: Curved great-circle flight arcs with animated directional pulses, **Hot/Cold proximity badges**, and **latitude + timezone deltas**.
- **Physical Geography Overlay (`🏞️ Rivers & Peaks`)**: Toggleable vector layer for **16 major world rivers** and **8 major mountain ranges**.
- **Persistent World Passport (`🛂`) & Expedition Flight Trail**: Tracks discovered cities in `localStorage` across sessions and plots your connected 10-city geodesic flight path at the end of each expedition.

## 🚀 Running Locally

`index.html` is 100% self-contained with zero external build steps or library dependencies. Open `index.html` directly in any modern browser or serve via any static HTTP server.
